# TRUEWATCH edge service — Phase 0 scaffolding.
# Versions are pinned as each phase introduces the dependency it needs.
# Nothing here is installed by `npm run setup`; the edge service has its own
# virtual environment (see edge/README.md).

# --- Service (Phase 1) ---
fastapi
uvicorn[standard]
pydantic
python-dotenv
httpx

# --- Decode and classical vision (Phases 1, 3) ---
opencv-python-headless
numpy

# --- Appearance channel (Phase 2) ---
# Inference runs on the exported ONNX model, so onnxruntime is the runtime
# dependency. Ultralytics is a TRAINING dependency and is declared in
# training/, not here — see training/README.md for the licence note.
onnxruntime

# --- Tracking and tiling (Phases 5, 6) ---
# lap / scipy for ByteTrack association, sahi for tiled far-field inference.

# --- ANPR, face, explanation (Phase 7) ---
# paddleocr / paddlepaddle for PP-OCRv5 Devanagari.
# YuNet ships with OpenCV's model zoo.
# transformers + torch for Moondream 2.

# --- Semantic footage search (Phase 6) ---
# SigLIP (google/siglip-base-patch16-224) via transformers, on CPU torch. See
# edge/search/embed.py's module docstring for why plain transformers+torch
# was chosen here over an onnxruntime export of SigLIP's dual encoder: the
# call rate (once per keyframe at index time, once per typed query) never
# competes with the frame-rate-bound ONNX appearance model above.
transformers
torch
pillow
sentencepiece

# --- Tests (Phase 4 onward) ---
pytest
